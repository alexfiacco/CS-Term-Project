b107 · Pick films from Browse into a list
Every film, Best for you with @movies123, signed in. Today (origin/main 37c7017b) the count line's ⋯ on the iPhone's Browse offers only Add all 30 to a list: "30" is the films the grid has loaded so far (the server sends 30 a page, so it reads 60, 90 as you scroll, capped at 100), not the 900+ in the header. Select already exists as one shared piece (GridSelect, SelectBar, AddToListSheet) on the profile's Films and Watchlist, lists, and lane, theme and person pages, and on the web's Browse. The iPhone's Browse turns it off (noSelect: true) because SelectBar swaps out a page's top bar. Proposed: turn it on here, with a bottom bar in place of the tabs, and use the same look on every grid.
1 · Now
The ⋯ as in the screenshot
  • One row: Add all 30 to a list. It adds the loaded films in the grid's order, so the number moves as you scroll and has nothing to do with 900+.
  • No way to choose which films go in.
2 · The ⋯, proposed
Select films, no bulk row Recommended
  • Select films starts Select mode.
  • Drop "Add all 30" on Browse: with 900+ films any number is arbitrary, and it changes as you scroll. Keep Add all N only where the grid holds every film (a list, the watchlist, a person page fully loaded).
  • If it must stay, call it Add the top 30 to a list, which is honest on Best for you but odd on Newest.

  • A tap ticks a poster: a cream ring and a cream check badge; matched posters keep their %. Unpicked posters show an empty ring.
  • The top bar becomes Cancel · 3 selected; the tabs become a pinned bar with Add 3 to a list (off until one is picked).
  • Scroll loads more as now; picks are kept by film, so a filter change keeps them.

The existing add-to-list drawer, "Add 3 films"
  • AddToListSheet as today: the posters, New list "Starts with these 3", then your lists.
  • A row tap adds what is missing, says "Added 2 to Best of the 50s · View", ends Select and closes. "1 of the 3 already here" stays blue.
  • Only the title changes: "Add to a list" to Add 3 films, the kicker "To a list, from Every film". The tick is the one red.
What Add all 30 adds
The films the grid has loaded, in its sort: /api/browse pages 30 at a time (PAGE = 30), and the ⋯ gets model.films, so it is 30 at first, then 60, 90. Past 100 it reads "Add the first 100". The 900+ in the header is the server's total, which it never touches.
Which grids share it
Browse, iPhoneSelect off (noSelect: true): the one to turn on here
Browse, webSelect on (BrowseSheet GridMore + SelectBar)
Lane, theme, personSelect on: TagPageScreen / TagPage.tsx, one screen for all three
Watchlist, your filmsSelect on: ProfileLibrary / IdentityView
Someone's listSelect on: ListScreen (your own list has no ⋯ add)
All of them use GridMoreButton, GridSelect, .selectable, SelectBar and AddToListSheet (ListsCore.swift; Lists.tsx on the web). So the cream ring and the bottom bar are one change in ListsCore and Lists.tsx, and every grid gets them. List view (rows) keeps Select off, as now.
Differs from what ships
Today a pick is a solid blue circle on a 55% shade, and SelectBar is a top bar with "Add to list (3)". This mock moves the button to a bottom bar (reachable, and Browse keeps its top) and makes the mark cream with no shade, so the % stays readable. That is a visual change on every grid above, so it needs your yes.
