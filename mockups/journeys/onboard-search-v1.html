Onboard search v1

A way back to search while rating the taste deck. Today search lives only on Rate films you love, the screen before the deck, and it shows only on a first run (no saved run, no taste yet). Once the deck opens there is no search and no way back to that screen: Close leaves onboarding, and reopening goes straight back to the deck. Both versions below reuse that screen's search (/api/search, posters only) and its rating drawer, and count the rating toward the same 30.

9 of 30 rated, on Drive. Eyebrow, count, the Film DNA tease and Close in the header; the bar; the card. Nothing on screen searches.

Now · the deck

Today's deck at 9 of 30. To rate a film you love that the deck hasn't dealt, there is no way in: the search box was one screen back, and that screen does not come back once the deck has a saved run.

A · Search in the header

One more 36 circle in the header row, a Lucide search icon between the count and the tease. Tap it: a search sheet with the keyboard up. Pick a film: the same rating drawer Rate films you love uses. Rate it: the drawer drops and you are on the same card, one more counted.

Never in the way. The circle sits with the other header controls; the card, stars and answers do not move. The 44 targets (dashed) touch but do not overlap.

The search box from Rate films you love, in a sheet: the same endpoint, 150ms after typing stops, only films with a poster. A rating here counts toward your 30. Cancel or a swipe down returns to Drive.

Today

  • Web: search is in LovedStart.tsx ("Search any film"), shown by HomeShell only when there is no taste and no saved run. TasteTest.tsx has no search; its header is eyebrow, count, DnaTease, Close.
  • iPhone: the same in LovedStartScreen.swift; OnboardingFlow sends Start to .loved only when nothing is stashed, else straight to .deck. TasteDeckScreen.swift has no search.
  • No way back: Close on the deck leaves onboarding (web to the start screen, iPhone to Welcome); coming back opens the deck again.

Pick · A

  • Out of the flow: the deck stays exactly as it is; the icon joins the controls already in the header.
