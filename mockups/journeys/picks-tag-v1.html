Recommendation: A, the tag on the poster

A removes the whole line and keeps the meaning. One word in the Trailer pill's glass on the poster's top left, the count as four dots inside it, and the title becomes the first thing under the poster (the card is a line shorter). It handles every label in code with one word: This week, Today, Last night, Starter, and nothing on every other card. The poster's three overlays sit in three corners, so it stays balanced. B is the safe fallback if he wants the label off the art (smallest code change). C crowds the match and floats alone when the match is hidden. D is cleanest but loses Today and Last night, which are worth saying. All four set "Because you loved…" in Bodoni roman with the film names in blue (soft underline kept so they read as links).
