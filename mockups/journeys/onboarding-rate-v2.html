Each chip is a jump link: it scrolls the page to that row (web scrollIntoView, iPhone proxy.scrollTo). It filters nothing and marks nothing. There is one chip per row from /api/start-films: the first row (it says "Trending this week" when there are 8 or more trending films, else "Popular this year"), "Everyone's seen these", seven genres, and "Modern classics". The genre rows (and their chips) reorder as you rate, so genres you rate in move up. On a 390pt phone only about two and a half chips show; the other seven sit off screen.

Proposed · 3 chips
Popular this yearEveryone's seen theseGenres

With more than about 5 rows, keep 3 chips: the first row, "Everyone's seen these" (where most first ratings come from), and Genres, which jumps to the first genre row. Because genre rows already move up as you rate, that row is the genre you rate most in, so one chip does the job of seven. "Modern classics" stays at the end of the scroll. Every row stays; only the chip row gets shorter, so the first screen shows three calm chips that fit on one line instead of a cut-off strip. Same on web and iPhone.

When it speaks
At most one line every 3 ratings, never at 8 (the halfway beat keeps its own toast), and only when a line is true. A run might sound like this:
a linehalfway beat, no line
The lines, and what makes each true
  • "Four 5★ already. You know what you love." Four or more 5★ so far (also "Three", "Five").
  • "You've seen 9 of 11." Rated vs cards shown, when you have skipped two or fewer.
  • "Nothing under 3★ yet. Generous." Six or more ratings, none below 3★.
  • "Half stars on three. Precise, noted." Three or more half-star ratings.
Out, by rule 853: genre leans ("Not a horror person"), strand names, any %. Each line is said once per run. It stops at 15, when the read itself speaks.
