Lists, v2: what changed

Three changes on top of lists-v1, nothing else moves. The profile's tabs are reordered. A list page gets the Films tab's own bar, Sort ▾, Filters and the grid / ranked switch, with List order as the default sort. And films go into a list in bulk: Select on any poster grid, or Add all to a list from the grid's ⋯, into the same Add to a list drawer, now for N films. The dashed yellow outlines mark what is new.
