b109 · One control row for every film grid
Owner: "grids show the same features inconsistently from screen to screen." Today the count is a caps label on one screen and a control on the next, the grid / list switch is a segmented pill on four screens and a ⋯ item on three, Seen / Unseen lives in Filters, in a chip, in a segment or in the count, and Select exists on some grids only. Proposed: one row, left to right: the count (the control when there is a choice) · Sort ▾ · Filters (40+ films) · ⋯, and the ⋯ always holds the same items in the same order. It is the lane page's row (rule 1800, b74 B) made the rule for every grid.

The rule

CountSort ▾Filters⋯

1 · Count

  • A choice: the count is the control, 15 semibold ink, muted ▾, 44 tall. N unseen ▾ (Unseen / Seen / All), N to watch ▾ (To watch / Rewatches), N lists ▾.
  • No choice: the same words, 15 medium muted, no ▾: 30 films.
  • Never caps, never on a line of its own.

2 · Sort ▾

A chip naming the sort ("Best for you ▾"), no "Sort" before it; direction inside its menu.

3 · Filters, by size

Shown when the page holds 40 or more films in all (before Show and filters, so it never blinks when you switch Unseen to Seen), or when a filter is on. "Filters · N" when set.

4 · ⋯, fixed order

  1. Show as list / Show as grid (tiers on a tier list)
  2. Select films
  3. Add all N to a list, only when every film is loaded

No grid / list switch anywhere. Nothing else in the ⋯. When the row does not fit, the group wraps under the count with the ⋯ pinned right (ControlRow).
