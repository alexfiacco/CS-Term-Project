Pitch copy v1: Set the scene

The owner: the empty Pitch page is too repetitive (kicker "PITCH", title "Pitch a film", placeholder "Pitch a film…", button "Pitch it", and under it "2 free pitches left this month": the word five times on one screen), and "something like Set the scene". Proposed: the title Set the scene, no kicker (the red dash moves under the title, still the screen's one red), a placeholder that changes every time the page opens, written as a Hollywood pitch line, Pitch it kept as the one place the page says the feature's name, and the free line trimmed to "2 free left this month". The Browse button keeps the name Pitch.

The empty page, iPhone
Today on the left, then four title combinations, each with a different rotating placeholder. The count under each phone is how many times the screen says "pitch".
The placeholders: twelve, one per open
Each is drawn at the box's real text width (288pt at 16pt Inter: 390 minus the gutters, the 14pt inset and the mic's 56) and must fit one line. "Pitch reads" is what lib/recut.ts and the settings vocabulary pull out of it if the person runs it as is: an anchor film (one per pitch), dials, length, decade, language, settings. All upright, no em dashes, none says "pitch".
  • Not used, from the brief: "Knives Out meets Parasite…" reads one anchor only (RecutQuery.anchor is a single film), so Parasite would land in "Not used"; rewritten as "Knives Out, but on a train…". "Here's the pitch: …" says pitch again. "Two words: rainy Sunday." repeats the Or try chip "Feels like a rainy Sunday", so it became "Two words: snowed in." "In a world where… (something cozy, under 2 hours)" is too long for one line; trimmed to "In a world… under two hours".
  • Famous lines only where they still parse: "Of all the casinos in the world…" (Casablanca's gin joints, reads Casinos) and "Here's Johnny: scary, 80s, short…" (The Shining, reads Scary, 1980s, Short). "We're gonna need a bigger boat" was tried and reads nothing ("boat" alone is not a setting word), so it is out.
  • Rotation: a new one on each open, shuffled, never the same twice running; none when the box is prefilled (Tonight's "Pitch it ›", a search's "Pitch this instead ›"). One list for web and iPhone (lib/recut.ts beside RECUT_EXAMPLES). The placeholder is a prompt, not a chip: it never runs on its own.

Recommended: A

  • No kicker, title "Set the scene" with the red dash under it, the rotating placeholder, "Pitch it", and the free line as "2 free left this month". The page says "pitch" once, on the button.
  • "Set the scene" is an invitation, and it pairs with screenplay lines in the box ("Fade in: …", "Picture this: …"). The Browse button and Pitch it carry the name, so the page never loses it.
  • The answered page keeps its caps "Your pitch" (rule 1138): that is where the name earns its place.

Keep "Pitch it"

  • It is the verb that spends a free pitch, the counter counts it, and Tonight's "Pitch it ›" opens this page; changing it breaks three places that already match.
  • Alternatives considered: "Roll camera" (cute, but unclear it runs), "Find it" (generic). Neither says what is being spent.
  • If the owner wants the name in the header too, B (kicker PITCH over Set the scene) is the fallback, at two mentions.
