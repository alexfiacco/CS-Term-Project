Pitch: friends from the names you say

You dictate (or type, without an "@") "something scary for me and Jake and Sam". When dictation ends, or you stop typing, the phrase's names are matched only against your taggable friends (mutual, sharing their ratings, not blocked), on the device, from the friends list Pitch already loads. Nothing is added until you tap. One tap turns the names into friend tokens; a name that fits more than one friend asks "Which Jake?" first. A name that fits nobody stays a plain word, with no message. Up to 4 friends, as today.

iPhone

The suggestion sits under the box, where the @ list appears. The names it will change are dotted in the box so you can see which words go.

Recommended: one line, one ＋, ask only when unsure REC

One tap for the common case (every name fits one friend), and the pop-up only for a real tie. The line uses the space the @ list already takes, so the page does not jump. The dotted names show exactly which words will turn into tokens.

Matched on the device against the friends list Pitch already fetches (tagOptions / PitchFriendRef); no new request, no names sent anywhere. The pitch still sends ids only (rule 1178).

Not chosen: a ＋ chip per name

"＋ Jake" "＋ Sam" as separate chips lets you add one and not the other, but costs a tap per friend for the usual case, and the ignore path is the same either way (leave it and the words stay). If you want one name only, take the other token out with one backspace after.
