In both, the avoid-list flag no longer needs a tab: it sits in the hero under the caption line, the only red on the screen, and a tap on it jumps to the guide. Substances level (Mild)Only a yes/no "drug use" warning (5.0% of films)New label trait, same pass. Until then the row is hidden.

The flag, the warning chip and the three label levels all run on data we hold today, so either option can ship before the two new traits and the TMDB pass, with fewer rows.

Recommendation: A, the guide inside Details

It is the owner's first instinct. The guide stops being "its own thing": it is the end of Details, the tab that already carries "Rated", so the rating and its explanation live together and there is one home for facts about the film.

The tab row stays at four and fits at 375pt. B's full "Parents guide" overflows the iPhone row by about 22pt, so it either scrolls (Themes slides off, on the page where the tabs are meant to be seen at a glance) or becomes "Guide", which is vague.

The part that matters most no longer needs a tab. The avoid flag is in the hero for both options, so the one thing a parent must not miss is seen before any tab; Details only has to carry the full picture for whoever goes looking, and a tap on the flag takes them there.

The cost: Details becomes the longest tab (about 560pt on the iPhone). The web halves it by setting the guide beside the facts. If the owner later finds parents never scroll past Studio, B with "Guide" is a one-line change from A, since the guide block is the same component in both.

Build order: hero flag and Details with today's data (badge, three levels, warnings, release date, runtime, language, country, original title, collection, genres); then the TMDB pass (studio, budget, box office, the viewer's own rating); then the two traits fill Language and Substances.
